# 为什么要做（Why）

本轮目标不是“再补一套统一模板”，而是把 `spring-core-beans` 文档中已经存在的机制/源码/排障主线进一步做成**可对照、可自证**的形态：在读者读到关键结论、关键分支、关键边界时，就地给出对应的 Spring/Spring Boot 官方参考入口，减少“读完再去翻文档”的上下文切换成本。

面向读者画像（已有 Spring 经验、希望更偏机制 + 源码 + 排障）：

- 需要把“我理解了”变成“我能用断点/官方语义/源码入口证明它”，避免纯主观记忆。
- 需要在排障时快速回答两个问题：
  1) 这个行为在官方语义里属于哪个概念/边界？
  2) 我现在看的源码分支，官方文档有没有明确说明触发条件？

本轮重点是“正文就地下压”，不新增统一栏目，不做固定填空式模板。
