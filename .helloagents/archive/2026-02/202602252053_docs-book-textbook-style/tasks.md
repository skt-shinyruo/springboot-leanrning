### 写作规范要点（供执行阶段引用）
- 主线章节定位：只做“学习引导与聚合”，不复制模块正文；正文以链接与清单为主。
- 每章固定小节：学习目标 / 概念框架 / 实验入口 / 常见误区 / 练习 / 小结 / 延伸阅读。
- 链接规则：优先链接到稳定入口（模块 `*/docs/`、模块 README、测试/示例入口）；尽量使用仓库内相对路径，保持可点击与可维护。
- 命名规范：`docs/book/` 下文件名使用两位序号前缀（如 `01-...md`），与 SUMMARY 顺序保持一致。
