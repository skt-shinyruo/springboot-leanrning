# 怎么做（How）

## 1. 版本语境（统一前提）

- Spring Framework：`6.2.x`（本仓库基线：`6.2.15`）
- Spring Boot：`3.5.9`

正文中的官方参考链接会显式标注“适用版本语境”，避免读者混用不同大版本的语义差异。

## 2. 下压策略（不做模板化）

对每个章节按其主题选择最相关的官方参考页（必要时到具体小节页面），并把链接放到**关键结论附近**：

- 机制主线的入口处：用 1 行“官方参考”把该章的主语义锚定到 Reference 对应页面；
- 关键分支/边界处：当正文出现“何时会走分支/为什么会失败/何时会被代理替换”等结论时，就地补 1 行官方入口，帮助对照验证；
- 避免重复：同一章里不机械重复同一组链接；若导读已有链接，则正文只补最关键的 1–2 处“就地参考”。

## 3. 覆盖范围

- 目标目录：`spring-core-modules/spring-core-beans/docs/**/*.md`（排除 `deepening-strategies/**` 作为单独决策项）
- 对缺少 `## 机制主线` 的章节：选择最贴近“读者会产生疑问的位置”（例如目录/索引/自检/训练包的“如何使用”段）放置就地参考。

## 4. 回归与同步

- 运行：`mvn -q -pl :spring-core-beans test`
- 更新知识库：`helloagents/wiki/modules/spring-core-beans.md`
- 更新变更记录：`helloagents/CHANGELOG.md`
- 迁移方案包到：`helloagents/history/2026-02/`
