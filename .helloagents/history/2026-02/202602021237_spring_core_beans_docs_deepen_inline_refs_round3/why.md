# 为什么要做（Why）

上一轮已把官方对照入口下压到各章“机制主线”附近，但真实阅读/排障时，读者最需要对照的位置往往不在主线开头，而是在：

- 关键分支的触发条件（为什么会走到这个分支）
- 关键异常/失败形态（为什么是 NoSuch/NoUnique/BeanCurrentlyInCreation）
- 关键边界与误判点（为什么“看起来能用”但其实不安全/不稳定）

本轮继续深化：把 Spring/Spring Boot 官方 Reference 的对照入口进一步下压到这些“关键结论/关键分支段落”旁边，让读者在读到结论的同时就能马上对齐官方语义，减少上下文切换与记忆偏差。
