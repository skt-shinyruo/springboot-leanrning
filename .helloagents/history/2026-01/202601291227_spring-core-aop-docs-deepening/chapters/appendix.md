# 章节逐章补强建议（appendix 附录）

### 第 40 章：90. 常见坑位（common pitfalls）

- 建议用“症状 → 根因 → 如何验证 → 修复方式”的结构组织（读者更像在查手册，而不是再读一篇文章）。
- 将坑位与 Guide 的分支矩阵联动：pitfalls 给“经验型结论”，分支矩阵给“定位路径”，两者互链避免重复。
- 覆盖 AOP 最常见坑：不生效（自调用/代理限制/切点不命中）、代理类型不符合预期、顺序异常、多代理叠加导致行为变化等，并为每个坑提供最小验证入口（测试/断点）。
- 建议在每个坑条目末尾标注“推荐回读章节”，形成从“排障”回到“理解”的学习闭环。

### 第 41 章：99. 自测与练习（self check）

- 建议按 Part 分组出题：Guide（主线/断点/矩阵）、Fundamentals（代理类型/自调用/final/exposeProxy）、AutoProxy/Pointcut（创建与匹配）、Stacking（叠加与顺序）。
- 增补“可运行自测入口”：让自测题不仅是问答，也能通过一个或多个 Exercise/Lab Test 验证答案（读者能自己证伪/证实）。
- 增补“标准答案的解释路径”：不只给结论，更要给“验证路径”（在哪个断点看到什么、哪个对象字段证明了什么）。
